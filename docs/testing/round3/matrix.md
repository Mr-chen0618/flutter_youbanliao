## 刷新逐页代码核查

原生RefreshIndicator：首页、搭子列表、广场发现/关注空态、我的动态各Tab、搜索结果含空态、动态详情评论含空态。BusinessRefresh封装：消息/分类通知/黑名单/聊天、个人中心、用户详情、活动详情、我发布/参加各筛选、信誉记录；相应child均设置AlwaysScrollable。表单和选择器保留输入/选择，不以刷新重置用户填写。SquareNotifier.refresh只读仓库，不再保存旧快照后覆盖磁盘；其余刷新错误走Toast并保留当前展示。上述为代码覆盖核查，自动化仅执行代表性广场互动刷新和既有首页失败恢复。
