# 2026-11-17 空态插图与关注页独立验收

范围：正常无数据状态接入用户提供的插图，保留表单入口、刷新、真实关系数据和提示；加载失败、加载中和权限状态仍单独显示。前轮 [11-17 关系流程](iteration-2026-11-17.md) 的样式证据为历史。本轮基于工作区未提交源码，最终快照见证据指纹。Widget 环境为 macOS、Flutter 3.35.7 / Dart 3.9.2，隔离 Mock 样本，启动 `Application(MainTabShell)`，375×812 逻辑像素；不是 iOS 模拟器或真机。

## 设计基准与缺陷

官方 Figma `sZdTOBC0a94JYUYKgAJr8e` 两截图原图均为 375×812：关注空 [2920:25469](empty-state-2026-11-17/figma-following-empty.png)；关注非空 [2929:25741](empty-state-2026-11-17/figma-following-populated.png)。空稿顶部标题不含 `(0)`，选中显示黄色弧线，空态包含138×138插图区域、13px提示和黄色找人聊聊；本轮用用户插图替换灰色占位。非空稿标题示例「关注 (4)」，列表头像 48 逻辑像素，昵称下城市｜年龄｜找搭子；首个 Tab 的「旅游足迹」与关系语义和空稿冲突，实际统一用「关注」。样本人数、头像与昵称均由应用数据驱动。

REL-01（P2）：旧实现标题 `(0)`、矩形 Tab 标记、默认 ListTile、缺少第三段辅助文案；向 developer 派发。开发为三组空/非空状态采用共用页面、弧线、专用行、标题及CTA，粉丝/好友刷新不再等待无关关注仓库。编排基准来自 Figma，真实用户需要等待载入及黑名单过滤。

EMPTY-LOAD（P2）：旧搜索从 `feed.value` 单值派生，初次加载与失败可错误表现为无结果；广场「发现」与「关注」若共用关注引导文案会误导。开发调整独立反馈分支。消息和广场的初始种子由 `MainTabShell` 首次苏醒门槛统一管理；关注源加载/失败单独处理。以下分别记录源码核查和实际执行范围。

## 全项目源码盘点

`rg -n 'AppEmptyState\(' lib/features` 命中 16 个业务源码文件、18 个构造调用。多个 Tab/过滤状态共用同一调用，各自保留动态文案。`pubspec.yaml` 注册 `assets/shared/`；文件 `no_data.png` 为 1050×1050 RGBA，统一组件渲染138逻辑像素，紧凑场景72，按设备像素比缓存。

| 流程 | 正常无数据覆盖 | 保留/分支检查 | 证据范围 |
| --- | --- | --- | --- |
| ES01 首页与搜索 | 首页友伴、活动；分类列表；已提交关键词且0结果 | 未输入仅引导；加载、失败及重试仍独立 | 源码；已有首页空/失败Widget |
| ES02 通信 | 会话列表、公告内容、空聊天记录、黑名单 | 首次载入失败主Tab重试；聊天不存在和被拉黑仍按独立语义；消息输入区仍可用 | 源码；旧消息流程回归不覆盖每个空态 |
| ES03 广场 | 发现、关注、我的动态状态、无评论 | 发布/评论输入仍在；发现/关注用各自文案；关注加载失败先反馈 | 源码 |

资产不是奖券、余额或会员卡的业务内容占位；相册有自己的上传卡。头像缺失走头像兜底，搜索未开始走提示，输入验证/内容下架/权限限制走对应状态。以上分支无需因为缺数字或文本字段就显示整页无数据插图。

## iOS 实际运行与剩余验证

主 Agent 在 iPhone 17 Pro / iOS 26.1 模拟器上用内置本地审核账号的 Mock 样本，完成 Debug 构建、安装和启动，并观察实际 App 从首页进入「我的」。该安装包为本轮初版，未含最后补充的城市搜索空态。「关注」点击及页面截图未完成：模拟器窗口变化后，按当前反馈停止逐屏操作。此段为主 Agent 运行记录，独立 tester 未操作设备；没有实测截图可与 Figma 两图并排比较。

已完成：16 个业务文件、18 处空态调用源码盘点；Figma 关注空/非空截图核查；正常入口到关注、空Tab切换、查找CTA、非空计数、对端详情的 Widget 回归；iOS 初版启动与“我的”入口冒烟。

未完成或未验证：最终源码的模拟器关注页空/非空排版与颜色、其他代表性页面空态设备渲染、真机视觉；没有把本轮源码覆盖数描述成 18 处全部设备通过。搜索加载/失败与权限边界本轮为源码检查；只有关系加载（及既有首页失败重试）有对应 Widget 执行。
