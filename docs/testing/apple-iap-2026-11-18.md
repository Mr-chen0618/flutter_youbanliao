# 2026-11-18 苹果内购客户端验证

## 范围与环境

macOS 本地 Flutter / Dart 3.9.2 工程，iOS bundle `com.djhl.youbanliao`、最低 15.6；插件 `in_app_purchase 3.2.3`、`in_app_purchase_storekit 0.4.8+1`，StoreKit 2。源码变更范围见 [实现记录](../ui-structure/apple-iap-2026-11-18.md)。本报告仅验证本轮客户端与既有主导航入口，不代表所有历史工作区改动通过。

用户确认六个商品均为消耗型、暂无后端。测试使用 fake 商店与 fake 验证发放仓库，不向真实 Apple ID 购买，不声称实际收据已验证。默认仓库未配置，真实付款按钮关闭。
