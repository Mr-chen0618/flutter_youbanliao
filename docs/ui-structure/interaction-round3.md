# 本轮交互整改

- 登录验证码四位8888，产品成功提示为「发送成功」。输入校验、操作成功失败均经AppToast，加载失败仍可固定空态重试，不让临时错误改变表单布局。
- AppMediaPicker使用image_picker系统相册选择，校验20MB及图片codec后复制至应用支持目录media。取消不改变业务数据；权限失败以业务提示处理。注册/编辑头像、动态/活动照片、聊天图片、举报与反馈附件共用该入口。AppImage识别绝对路径与file URI，原asset/network/base64行为保留。发布动态图标为SVG资源，公共AppImage按扩展名通过SvgPicture.asset渲染，保留尺寸、比例和可选颜色，避免普通位图解码器无法显示矢量图标。
- 动态发现与详情更多共用拉黑、举报；发布最多九张照片、位置、可见范围及规则说明按3168:8861。计数保存基础likeCount/commentCount；交互点赞在基础数上加一，取消恢复，正数展示数字。
- 邀约仓库先将结构化邀约卡写入messages/inbox，再写home/invites。stable peerId关联接收者；idempotencyKey由对象/活动时间/标题构成，第二步失败后重试不重复发卡，缺草稿拒绝提交。Provider同步当前消息后调用仓库，结束后重新读取消息，失败仍可重试。黑名单兼容稳定ID与唯一昵称历史记录。
- 广场/我的动态/详情评论、消息/通知/聊天/黑名单、个人/用户/活动详情、信誉/我的组队以及搜索结果支持下拉刷新。空列表保持可滚动，刷新等待真实数据读取；快照型列表刷新只读队列，不以旧状态覆盖磁盘。初次加载失败可重试，刷新失败Toast并尽量保留旧列表。
- 资料签名/昵称、城市、兴趣、退出确认与动态详情由对应新稿补齐，详见profile-edit-round3.md及square.md。所有修改均未操作模拟器，由用户进行最终视觉及设备验收。
