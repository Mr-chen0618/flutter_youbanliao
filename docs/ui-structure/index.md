## 分层与公共能力

- 数据访问契约位于 `data/repository/` 或原有的 `data/server/`，Mock 实现位于 `data/mock/`。持久化快照与实体位于 `data/model/`，业务枚举与表单请求分别放在 `data/enum/` 和 `data/request-model/`。旧仓库入口保留为导出文件，已有调用可继续使用。
- 页面读取 Provider，Provider 装配仓库。活动发布的登录检查和提交位于 `activity_publication_provider.dart`。活动详情、用户详情和聊天通过 `RouteNames`、`AppNavigator.pushNamed` 和 `AppRouter` 传递 ID。
- `ActivityInviteActionWidget` 供首页搭子卡片和用户详情复用，使用活动模块的邀约 Provider 和 Repository。继续读取 `home/invites.json` 对应的本地记录，保留已邀约状态和草稿。
- 公共反馈沿用 `lib/shared/widgets/feedback/app_toast.dart` 的 `AppToast.show`，由邀约操作提交成功后调用。持久化继续使用 `lib/core/storage/mock_json_store.dart` 的 `MockJsonStore`，由各 Mock 仓库读取及更新 JSON。
