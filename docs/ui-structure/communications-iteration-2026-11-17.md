## 业务与数据

openConversation(peerId, name, avatar) 以真实对端 ID 复用或创建空会话，精确迁移旧版无 peerId 的会话。已拉黑用户返回 null，历史会话解除拉黑后恢复。通知、黑名单、举报、通话记录与消息共用现有账号隔离的 JSON 存储。

语音消息通过 record 在用户长按后申请麦克风权限，保存 AAC 文件。录音文件分账号目录。上滑取消、时长不足一秒、页面退出和切后台结束录音并清理临时文件。audioplayers 播放实际文件，文件丢失给出 Toast。

语音和视频呼叫实现本地状态演示，Debug 构建通过调试接通按钮进入接通状态，Release 构建拨出后等待无应答且隐藏调试按钮。视频画面使用对端资料图片与本人头像，麦克风、免提和摄像头按钮驱动本地 UI 状态。RTC 远端音视频、远端接听推送、远端忙线状态需要接入真实服务。当前可依据本地资料拦截已被对端拉黑，依据本地会话拦截重复通话。已有目录缺少显式在线字段，离线和远端忙线鉴权需要服务数据。通话取消、拒绝、超时和结束记录写入对应会话一次。

举报使用现有本地仓库保存，成功页标明「举报已保存」。服务端审核和处理结果需要后续服务接入。

Figma 的通话和举报 SVG、渐变与背景图片已下载到 assets/messages，运行时引用本地资源。内容头像和用户照片来自业务资料。
