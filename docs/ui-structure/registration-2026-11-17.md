## 当前行为及复用

- AuthGate 登录后发现 `profileCompleted=false` 进入本页，成功后由既有会话刷新进入首页。
- 昵称弹层复用 AppTextField、InputValidator 和 AppToast，允许最多7字符并沿用原有效昵称规则。随机昵称在主表单直接更新。
- 生日复用 `ProfileBirthdayPage(asSheet: true)`，新增可选 `maximumDate`，注册最多为昨天，旧调用保持其缺省截止日。取消不回写日期，自动处理年月日滚轮。
- 男/女头像引导复用 `showProfileAvatarGuide`、原有10张规则示例与 AppMediaPicker，用户确认后才启动系统选图。共享头像引导的标题区按这行设计重排，米色圆形关闭按钮与样例头像并排叠放。取消不修改头像，性别改变后保留已选本人照片，后续头像引导使用当前性别。
- 性别默认男来自进入稿。点另一个性别立即选择并展示不可更换说明，注册完成后继续遵循原锁定契约。
- 按本次稿与根 Agent 确认，返回只展示“只差一步就注册成功了！退出也太可惜了”，点“我知道了”继续填写。该约定覆盖旧 `auth.md` 中“返回登录并 signOut”的记载。没有隐式返回次数规则。
- 昵称、生日、性别、头像变更均为提交前草稿。完整提交复用 AuthRepository.completeProfile，只在全部必填校验和账号落盘成功后进入首页。防双击、失败保留表单、账号隔离及既有磁盘契约继续使用。重启后未完成账号重新进入引导，未新增跨进程草稿恢复契约。
