## 实现与理由

- `lib/features/teen/data/teen_mode_repository.dart` 负责设备级 `device/teen_mode.json`，首次 initialize、串行存取。使用安全随机盐和 SHA256 摘要，磁盘不存明文 PIN。设置与注销/切换账号隔离，防止退出账号绕开监护限制。
- `presentation/teen_mode_provider.dart` 提供 teenModeProvider 与 enable/disable，持久化成功后才发布状态，错误密码不关闭。
- `presentation/teen_mode_page.dart` 提供 TeenModePage 与根级 TeenModeGate(child:)。启动加载或错误时不显示平台内容；已开启时使用独立 Navigator 覆盖原导航，返回手势不能离开。独立导航承载密码页和退出成功页；成功页点击返回首页后才恢复底层。
- `user/presentation/pages/profile_settings_page.dart` 增加入口，保留全部已有设置。
- SVG 从对应设计资源下载到 `assets/profile/teen_umbrella.svg`、`teen_enabled.svg`、`teen_success.svg`、`teen_pin_empty.svg`；均非空，本地渲染且无临时 URL。插画180×150、状态52×52、成功96×96、空密码位12×12按设计基准缩放。

设计明确“全部平台内容与服务暂停”，采用根级整页守卫；并非仅隐藏付费按钮。根 `main.dart` 由整合 developer 负责接入。此本地监护能力不等同服务端家长控制。
