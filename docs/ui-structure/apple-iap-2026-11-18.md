## 模块与复用

独立 `features/purchases` 负责交易生命周期、商品目录、权益快照和验证发放契约；user 页面仅组合入口与状态，不将付费余额写入磁盘 Mock。复用 Riverpod 注入、authSessionProvider 账号上下文、AppImage 资源、原有 ShopHero/OptionTile/Footer 及 AppToast 协议未配置反馈。交易状态在页面内展示，页面退出不移除交易监听。已有 MockJsonStore 不是可信订单账本，因此不用于真实交易落账。

- `data/model/apple_product.dart`：六个商品的类型化目录。
- `data/server/apple_purchase_gateway.dart`：封装 `in_app_purchase` 和 `in_app_purchase_storekit`；使用 StoreKit 2 的商品类型、`Sk2PurchaseParam`、`SK2Transaction.unfinishedTransactions()`。
- `data/repository/purchase_fulfillment_repository.dart`：后端契约和未配置实现；`accountToken` 返回当前服务端认证用户的稳定 UUID，`verifyAndDeliver` 必须原子验证与幂等发放后再返回账号权益快照，`loadEntitlements` 支持跨设备重新加载。
- `presentation/providers/apple_purchase_controller.dart`：应用级队列处理 pending/canceled/error/purchased/restored；不将买单接口的 true 当成功；成功验证并发放后才 complete；失败保留未结束交易及重试入口；同次启动重复回调跳过重复发放；重启依赖服务端交易 ID 幂等。
- `presentation/providers/apple_purchase_provider.dart`：平台门控、应用级注入和状态流；真实后端替换 `purchaseFulfillmentProvider`，默认 `UnavailablePurchaseFulfillment` 拒绝支付。
- `app/bootstrap/application_bootstrapper.dart`：依赖初始化时监听并主动补查未结束交易，不等待充值页打开。
- `user/presentation/pages/profile_shop_page.dart`：真实商店价格、商品切换、禁用/处理中、商品刷新、待确认交易重试；已验证权益按当前账号读取，金币卡和会员有效期更新。

依赖固定 `in_app_purchase: 3.2.3`、`in_app_purchase_storekit: 0.4.8+1`（适配当前 Dart 3.9.2），使用该版本默认 StoreKit 2。iOS Runner 最低 15.6，bundle `com.djhl.youbanliao`，项目添加 In-App Purchase capability；没有生成或更改签名证书、App Store Connect 商品配置。

## 交易与账号约定

购买前检查商店可用、商品存在且为消耗型、已登录、无正在处理或未解决交易、后端已配置。服务端分配 UUID 传入 appAccountToken，不把 Mock 用户 ID 当 UUID。token 获取期间切换账号会停止发起购买。交易结果归属由后端根据签名交易 token 确认，不能按回调时登录用户发放。客户端权益快照按 accountId 隔离；慢速读取不能覆盖新发放快照。

未校验或未发放交易不 finish；finish 失败可重试且不再次发放。启动主动查询 StoreKit 未完成交易；查询失败阻止新购买并提供重试。消耗型商品不承诺通过 restorePurchases 恢复已消费权益，余额/固定月数会员需要后端保存并加载。退款和撤销仍需后端处理。
